# Git Graph Local Viewer

Web app local de doc metadata Git tu repo tren may va hien thi commit graph dang node/branch trong trinh duyet.

## Chay app

```bash
npm start
```

Mac dinh app mo server tai `http://127.0.0.1:4173`.

## Cach dung

- App mac dinh doc repo tai thu muc hien tai.
- Neu thu muc hien tai khong co `.git`, nhap duong dan repo khac hoac nhap truc tiep duong dan den `.git`.
- Frontend se ve node commit, duong branch/merge va cho phep bam vao node de xem chi tiet commit.

## Ghi chu

- Khong can cai them package.
- Backend su dung `git` co san trong may de lay commit graph.
